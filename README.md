# Diego Jorquera — Portfolio

Personal portfolio built with Next.js 15, React 19, Tailwind 4 and Motion. Bilingual (English by default, Spanish via the EN / ES toggle).

Live at **https://djorqueradev.github.io** (GitHub Pages).

## Run locally

```bash
npm install
npm run dev   # http://localhost:3000
```

## Where to edit

| What | File |
|---|---|
| Name, email, GitHub, LinkedIn, CV link | `lib/site.ts` |
| Interface text (EN and ES) | `lib/i18n.tsx` |
| Projects (EN fields + `es` block for Spanish) | `data/projects.json` |
| Project screenshots | `public/images/...` |

Each project in `data/projects.json` has English fields at the top level and an optional `es` object with the Spanish version. Any Spanish field left empty falls back to English. `liveUrl` adds a **Visit site** button; `repoUrl` adds **View code**. Projects without screenshots get a generated cover.

## Project visuals

Set `cover` in `data/projects.json` to choose a project's visual:

| `cover` | What it shows | Component |
|---|---|---|
| `"enclosure3d"` | Interactive 3D model of the data-logger enclosure (drag to rotate, exploded view) | `components/enclosure-viewer.tsx` |
| `"quakes"` | Time-lapse of real Chilean earthquakes, USGS M5.5+ 1965–2016 (`public/data/chile-quakes.json`) | `components/quake-map.tsx` |
| `"browser"` | Screenshots inside a browser window, cross-fading | `components/browser-showcase.tsx` |
| _(none)_ | Screenshot carousel, or a generated cover if there are no images | `components/project-visual.tsx` |

`architecture` (and `es.architecture`) adds the "How it fits together" diagram to the case study. Animations pause off-screen and respect the system's *Reduce motion* setting. The share image is generated by `app/opengraph-image.tsx`.

## Publishing (GitHub Pages)

The site is a static export (`next build` → `out/`). The repository
[`djorqueradev/djorqueradev.github.io`](https://github.com/djorqueradev/djorqueradev.github.io) has two branches:

| Branch | Contains |
|---|---|
| `source` | This Next.js project |
| `main` | The built static site that GitHub Pages serves |

Push to `source` and the workflow in `.github/workflows/deploy.yml` builds the site and publishes it to `main`.
To publish by hand instead: `npm run build`, then copy the contents of `out/` to the `main` branch (keep the `.nojekyll` file).

## Admin panel (`/admin`)

Set `ADMIN_PASSWORD` in `.env.local`. The session cookie is signed with that password, so it can't be forged.

The admin only exists in `npm run dev` (its files use the `.dev.tsx` / `.dev.ts` extension, which the static build ignores). It writes to `data/projects.json` and `public/images/uploads`; commit those changes to `source` to publish them.
